# Persona publique : Nyx

La version publique d'Ani Local utilise **Nyx**, un personnage d'exemple
éducatif. Elle ne contient volontairement aucune donnée personnelle de
l'utilisateur ni aucun lore privé.

Le fichier `constants/aniPersona.ts` peut être adapté pour créer une autre
persona dans une installation privée.

## Objectif

Nyx sert à démontrer :

- une identité de personnage ;
- plusieurs modes de comportement ;
- des règles de fonctionnement ;
- une séparation entre le code public et les données privées.

Pour une installation personnelle, il est recommandé de conserver les
données privées dans une configuration locale non versionnée.
